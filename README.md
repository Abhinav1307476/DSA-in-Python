# DSA in Python

This repository contains beginner-friendly implementations of common linked-list data structures in Python.

## Files

- `01_SinglyLL.py` - Singly linked list
- `02_DoublyLL.py` - Doubly linked list
- `03_CircularSinglyLL.py` - Circular singly linked list
- `04_CircularDoublyLL.py` - Circular doubly linked list
- `05_stack.py` - Stack implementation

## What each file demonstrates

### 1. Singly Linked List
- Insert at beginning
- Insert at end
- Insert after a node
- Delete a node
- Display the list

### 2. Doubly Linked List
- Insert at beginning
- Insert at end
- Insert after a node
- Delete a node while updating both `prev` and `next`
- Display the list

### 3. Circular Singly Linked List
- Insert at beginning
- Insert at end
- Insert after a node
- Delete a node
- Circular traversal check

### 4. Circular Doubly Linked List
- Insert at beginning
- Insert at end
- Insert after a node
- Delete a node while maintaining circular links
- Circular traversal check

## How to run

From the project folder, run:

```bash
python 01_SinglyLL.py
python 02_DoublyLL.py
python 03_CircularSinglyLL.py
python 04_CircularDoublyLL.py
python 05_stack.py
```

## Notes

- These programs are designed for learning and understanding linked-list operations.
- Output is printed directly in the console for easy debugging and visualization.
- Error messages are kept consistent across the list types for a clearer learning experience.

## Learning goal

The aim is to understand:
- node structure
- pointer linking
- insertion operations
- deletion operations
- circular behavior
- traversal logic
