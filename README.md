# DSA in Python

This repository contains beginner-friendly implementations of common linked-list data structures in Python.

## Files

- `01_SinglyLL.py` - Singly linked list
- `02_DoublyLL.py` - Doubly linked list
- `03_CircularSinglyLL.py` - Circular singly linked list
- `04_CircularDoublyLL.py` - Circular doubly linked list
- `05_Python_F_Stack.py` - Stack using a Python list with the top at the end
- `06_Python_B_Stack.py` - Stack using a Python list with the top at the beginning
- `07_Stack.py` - Fixed-size stack implementation
- `08_BStack.py` - Fixed-size stack implementation using a `top` index
- `09_Python_Queue.py` - Queue using a Python list
- `10_Queue.py` - Fixed-size queue implementation
- `11_Python_Deque.py` - Deque using a Python list
- `12_Deque.py` - Fixed-size deque implementation

## What each file demonstrates

### 1. Singly Linked List
- Insert at beginning
- Insert at end
- Insert after a node
- Delete a node
- Display the list

### 2. Doubly Linked List
- Insert at beginning
- Insert at end
- Insert after a node
- Delete a node while updating both `prev` and `next`
- Display the list

### 3. Circular Singly Linked List
- Insert at beginning
- Insert at end
- Insert after a node
- Delete a node
- Circular traversal check

### 4. Circular Doubly Linked List
- Insert at beginning
- Insert at end
- Insert after a node
- Delete a node while maintaining circular links
- Circular traversal check

### 5. Stacks
- Stack operations using a Python list
- Fixed-size stack operations with overflow and underflow checks

### 6. Queues
- Queue operations using a Python list
- Fixed-size queue operations with overflow and underflow checks

### 7. Deques
- Add and remove items from both ends using a Python list
- Fixed-size deque operations with capacity checks

## How to run

From the project folder, run:

```bash
python 01_SinglyLL.py
python 02_DoublyLL.py
python 03_CircularSinglyLL.py
python 04_CircularDoublyLL.py
python 05_Python_F_Stack.py
python 06_Python_B_Stack.py
python 07_Stack.py
python 08_BStack.py
python 09_Python_Queue.py
python 10_Queue.py
python 11_Python_Deque.py
python 12_Deque.py
```

## Notes

- These programs are designed for learning and understanding linked-list operations.
- Output is printed directly in the console for easy debugging and visualization.
- Error messages are kept consistent across the list types for a clearer learning experience.

## Learning goal

The aim is to understand:
- node structure
- pointer linking
- insertion operations
- deletion operations
- circular behavior
- traversal logic
